localstack-s3-explorer

Browse local S3 buckets
without the AWS CLI

Interactive TUI and CLI to explore, search, preview, and download files from Localstack S3 during local cloud development.

Commands

s3explorer
Launch interactive TUI browser
s3explorer ls
List buckets or objects
s3explorer get
Download an object to local
s3explorer info
Show object metadata
s3explorer preview
Preview file content (text or hex)
s3explorer search
Search objects by key substring
